# 使用指南

[返回首页](../README.md)

## 安装与更新

1. 在 [下载页面](https://github.com/lhl1/youtube-progress-dub/releases/latest) 选择 ZIP，解压到长期保留的文件夹。
2. 打开 `edge://extensions`，开启“开发人员模式”，点击“加载解压缩的扩展”。
3. 选择直接包含 `manifest.json` 的文件夹，再刷新 YouTube 页面。

源码使用者也可以直接加载仓库中的 `YouTube中文同传/` 文件夹。下载包同时提供 CRX 与校验文件；非商店 CRX 可能被浏览器限制，推荐加载解压后的文件夹。插件目前没有上架扩展商店。

更新时替换扩展文件，在扩展管理页点击“重新加载”，再刷新视频页面。个人设置会保留。想使用推荐的默认值，在播放器设置中点击“恢复推荐设置”。

## 打开设置

点击播放器齿轮旁的白色“中文同传”图标。常用设置直接在面板中调整，自动保存；点击面板外、YouTube 其他按钮或按 Esc，面板会收起，朗读继续运行。

默认打开视频就自动开启同传。手动关闭后，当前视频保持关闭，下一条视频继续按自动开启设置运行。首次播放语音可能需要点击视频中的按钮。没有晓晓声音时可选择其他中文声音。

## 选择朗读方式

| 方式 | 播放效果 |
| --- | --- |
| 完整朗读（默认） | 每句读完再读下一句，不主动暂停视频。读不完时允许中文落后，视频结束后继续读完剩余内容。 |
| 跟随视频 | 尽量跟上视频进度。内容太密时，可能截断来不及读完的语句。 |

完整朗读时，中文字幕默认跟随当前读到的句子。手动暂停视频也会暂停中文，继续播放后接着读；拖动进度、切换视频或停止同传会清除旧位置的待读内容。声音恢复异常时，尚未完成的小片段可能从头重读。

基础语速会乘以视频倍速。例如基础语速 1.30 倍、视频 2.00 倍，实际朗读为 2.60 倍。新速度从下一朗读片段生效，待读内容会保留。

同传开启期间，原视频持续保持音量上限，默认 25%；句子之间也不会恢复大音量。原本比上限更小的声音不会被调高，停止同传后恢复原音量。

## 调整字幕

可以设置中文与原文是否显示，以及字体、大小、颜色、粗体、文字边缘、背景、透明度、位置、宽度和行距。经典、影院、大字、双语学习四种快捷样式可以直接选，面板提供实时预览。

字幕默认跟随中文朗读；也可以改为跟随视频，并调整提前或延后时间。这只改变显示时间，不改变视频进度或朗读。隐藏 YouTube 原字幕只影响显示，仍可读取字幕；无法隐藏已经录进视频画面的文字。

只有明确标记为自动生成的字幕才按意思分段，并把长句分页显示。分页不会丢字，也不会打断完整朗读。人工／原生字幕保持原条目；即便经过 YouTube 自动翻译，也不会按自动生成字幕处理。无法确定字幕类型时同样保留原条目。

## 翻译与长视频

默认优先使用可用的中文字幕，其他字幕通过 Google 翻译；英语自动生成字幕优先保留英文分段线索再翻译。翻译随进度准备，无需先等待整个视频翻译完成。拖动进度后优先处理新位置，回看时会使用缓存。

默认向前准备约 100 秒内容，可调整预读时间。网络超时或限流时会等待重试；完整朗读优先准备最早尚未读完的句子。网络和翻译服务仍可能影响连续性。

自定义翻译服务需在“翻译服务与缓存”中打开“配置接口与密钥”，填写 OpenAI 兼容的 Chat Completions 地址、模型名和密钥，再保存。支持 HTTPS 及本机 localhost／127.0.0.1 的 HTTP 服务；浏览器会申请对应域名权限。

默认翻译地址不需要密钥，但可用性不受本项目保证。自定义服务需返回 `choices[0].message.content`，使用非流式响应。

## 没声音或没有字幕

- 没声音：点击视频里的按钮，试听其他中文声音，检查系统与 Edge 音量，再点“恢复 / 重试”。
- 没字幕：先确认视频本身提供字幕，尝试手动选择字幕来源，再重试。
- 更新后不生效：重新加载扩展，并刷新 YouTube 页面。
- 双重朗读：关闭其他同类翻译或配音插件。

本插件依赖视频字幕，无法给完全没有字幕的视频直接识别音轨。翻译不是逐词同步，无法保证与人物口型一致。在线自然声音的可用性取决于浏览器、系统和网络。

仍有问题，请在 [Issues](https://github.com/lhl1/youtube-progress-dub/issues) 提供浏览器版本、插件版本、字幕类型、视频倍速和复现步骤，分享日志前移除密钥和个人信息。
