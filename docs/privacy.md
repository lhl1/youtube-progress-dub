## 数据保存在哪里

设置与翻译缓存保存在本机浏览器扩展存储中。本项目没有自建遥测、配音服务器或账号系统。

使用默认 Google 翻译时，需要翻译的字幕文本会发送到 Google。配置自定义翻译服务后，字幕发送到所选服务。1.7.0 的自动字幕翻译可附带前后各最多 400 字符的相邻源文，只用于理解当前段；默认 Google 模式不额外发送这两个上下文窗口。Edge 在线自然声音可能由浏览器在线合成，适用相应服务的隐私规则。

选择 YouTube 字幕翻译时，扩展从 YouTube 读取中文字幕或中文译轨。选择微软翻译，或主动勾选 Google 失败时使用微软备用后，待译字幕会发送到微软 Translator。微软密钥保存在本机扩展设置，只随微软 Translator 请求发送。自定义密钥只随请求发送给你配置的自定义服务。不要把密钥写进公开仓库或问题反馈中。

选择阿里云机器翻译后，待译字幕、AccessKey ID 和请求签名会发送到阿里云机器翻译接口。AccessKey Secret 保存在本机扩展存储，只用于本机计算签名。

选择百度通用文本翻译后，待译字幕、APP ID 和签名参数会发送到百度翻译开放平台。密钥保存在本机扩展存储，只用于本机计算签名。

选择实验性的 Bing 网页翻译时，扩展会在获授权后向专用 Bing 标签页填写待译字幕，并读取简体中文译文。Cookie 和验证码由 Bing 页面处理。扩展使用可选的脚本权限以及 cn.bing.com 和 www.bing.com 的访问权限实现此功能。

## 为什么需要这些权限

| 权限 | 用途 |
| --- | --- |
| storage | 保存设置与翻译缓存。 |
| webRequest | 观察 YouTube 字幕请求，取得字幕来源。 |
| activeTab | 操作当前视频页面。 |
| YouTube 和默认翻译域名 | 读取字幕并进行翻译。 |
| 可选翻译域名 | 启用微软、Bing、阿里云、百度翻译或配置自定义服务时，申请对应站点的访问权限。 |
| scripting（可选） | 在用户授权的专用 Bing 翻译页填写和读取翻译内容。 |

公开仓库不包含签名私钥、私人账号信息、本机备份、私人录屏或参考插件安装包。
