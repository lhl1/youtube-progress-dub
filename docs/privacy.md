## 数据保存在哪里

设置与翻译缓存保存在本机浏览器扩展存储中。本项目没有自建遥测、配音服务器或账号系统。

使用默认 Google 翻译时，需要翻译的字幕文本会发送到 Google。配置自定义翻译服务后，字幕发送到所选服务。Edge 在线自然声音可能由浏览器在线合成，适用相应服务的隐私规则。

自定义密钥保存在本机扩展设置中，并发送给你配置的翻译服务。不要把密钥写进公开仓库或问题反馈中。

## 为什么需要这些权限

| 权限 | 用途 |
| --- | --- |
| storage | 保存设置与翻译缓存。 |
| webRequest | 观察 YouTube 字幕请求，取得字幕来源。 |
| activeTab | 操作当前视频页面。 |
| YouTube 和默认翻译域名 | 读取字幕并进行翻译。 |
| 可选的自定义域名 | 仅配置自定义服务时，申请对应接口的访问权限。 |

公开仓库不包含签名私钥、私人账号信息、本机备份、私人录屏或参考插件安装包。
